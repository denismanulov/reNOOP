# Denis's iOS redesign — screen anatomy (source of truth for the Android M3 port)

Condensed from three read-only surveys of `Strand/` + `StrandiOS/` at HEAD a4695dd4. Paths relative to repo root.
Strings are iOS English; Russian from `Strand/Resources/Localizable.xcstrings` (`ru`).

## Shell
- 4 tabs (`StrandiOS/App/RootTabView.swift:241`): Summary `heart.text.square`, Sleep `bed.double`, Workouts `figure.run`, Browse `magnifyingglass` (search role). Re-tap active tab: pop to root, else scroll to top.
- Settings is NOT a tab: Summary avatar (a11y "Profile and settings") pushes Settings.
- "Now running" mini-player (workout / gym / intervals) above tab bar on every tab (`Strand/Fitness/NowRunning.swift`).
- Router: devices/insightsHub/labBook/journal/coach/heartRate(Live)/breathe open inside Browse; trends pushes on Summary; stress pushes metric page stress on Summary.
- Removed screens (commits e9c0ba85, 19cea7c5, 3a72c821, 4d53df5c, 309e5a6c, c2fb1f53, 63984147, cb91b323): Intelligence, Health screen (stale routes → All Metrics), Mi Band screen, Your Data Fused, Rhythm, Compare, Live Sessions, Stress screen (folded into Stress metric page), old Today/Liquid Today, old Trends/Explore, More tab.

## 1. Summary (`Strand/Summary/*`)
Top→bottom:
1. Large title "Summary" with 36pt avatar at right (photo / initials on grey gradient / person glyph) → Settings. No other toolbar buttons.
2. Health alert banner only when raised ("Signs of strain" / "Signals Outside Your Range" / "You logged feeling unwell").
3. Day pager: ‹ title › ; title "Today"/"Yesterday"/"Thursday, 24 September"; tap title → calendar (bounds: logical day 04:00, ≥ earliest data day, ≤ today). Pull-to-refresh = strap sync + reload. No swipe.
4. Rings card (no title): 3 concentric rings left (outer→inner Charge, Effort, Rest; fill = value/max clamped; track 26% opacity), right 3 figures: name + value in ring hue. Charge "72%" + caption "Last night · 24 Sep" / "Latest sleep · 3 Sep" / "Calibrating"; Effort "12.4/21" or "45.0/100" (UnitPrefs effort scale); Rest "85%". Tap Charge/Effort → metric page; Rest → Sleep page of that night; rings → Charge.
5. Fitness tiles (a4695dd4): 2 square tiles side by side, defaults Steps + Calories, user can change each (long-press "Change Card", any Key Metric except rings). Tile: title + chevron disc, stamp "Today", figure in metric hue, 7-day chart with weekday letters (bars for totals, dots for vitals). Tap → metric page.
6. "Pinned" + "Edit" (opens Key Metrics customisation):
   - Sleep card first if slept: `bed` "Sleep", stamp = wake time, "Time Asleep" "7 hr 12 min", compact stages chart. Tap → Sleep page for that night.
   - Pinned metric cards: icon+title in hue, stamp (Today/Yesterday/24 Sep) + chevron; value bold + unit; optional caption ("strap estimate (unverified)", "from profile"); 72×30 mini chart (line+end dot for vitals, bars latest solid for totals; nothing if <3 points). Default pinned (after rings/tiles removed): HRV, Resting HR, Blood Oxygen, Respiratory, Weight. Skin Temp opt-in.
   - Empty: "Pin metrics you care about" card → editor.
   - Last row "Show All Metrics" → All Metrics.
7. "Trends": up to 3 trend cards + row "Show All Trends" → Trends.
8. "Highlights" (hidden if none): ≤3 from ReadinessEngine signals, non-neutral, ordered bad→watch→good. Card: title row (HRV / Resting HR / Respiratory rate / Training load / Training variety), one sentence (`ReadinessCopy.swift`, e.g. "Your HRV is above your normal — you're well recovered."), hairline, two figures w/ capsule bars "Latest" vs "Your Normal" or "Last 7 Days" vs "Last 28 Days". Tap → metric (hrv/rhr/resp_rate; acwr/monotony → Effort).
9. Sync footer centred: "Updated Just Now" / "Updated 5 minutes ago" / "Syncing…".

Key Metric icons/hues: HRV waveform/Heart; Resting HR heart/Heart; Blood Oxygen drop/Oxygen; Respiratory lungs/Respiratory; Steps walk/Activity; Calories flame/Activity; Weight scale/Body; Skin Temp thermometer/Temperature.
Category hues (iOS light/dark): Heart #FF2D55/#FF375F, Respiratory #00C7BE/#63E6E2, Oxygen #32ADE6/#64D2FF, Temperature #FF9500/#FF9F0A, Body #AF52DE/#BF5AF2, Mind #30B0C7/#40C8E0, Nutrition #34C759/#30D158, Activity #FA3C1E/#FF5A36, Sleep #5E5CE6/#7D7AFF.
Metric→hue: recovery=ring Charge, strain=ring Effort, sleep_performance=ring Rest; resp_rate Respiratory; spo2 Oxygen; skin_temp Temperature; weight/body_fat/lean_mass/bmi Body; stress/mood Mind; else by category Heart/Charge→Heart, Rest→Sleep, Effort→Activity, Nutrition→Nutrition, else Body.
